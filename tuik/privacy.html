Tuik 개인정보 처리방침

시행일: 2026년 11월 9일 · 운영자: JONG SEON WOO

이 방침은 Tuik의 iPhone·Android 클라이언트와 Windows·macOS 데스크톱 연결 기능에 적용됩니다.

개발자에게 전송하는 정보

Tuik에는 개발자가 운영하는 중앙 작업 서버, 광고 SDK, 분석 SDK 또는 추적 기능이 없습니다. 개발자는 앱을 통해 사용자의 터미널 내용, 작업 큐, 실행 기록이나 기기 등록 토큰을 수집하지 않습니다.

사용자 기기에 저장하는 정보

연결한 PC에는 프로젝트 경로, 작업 큐, 공통 프롬프트, 실행 기록과 등록 기기 정보가 저장됩니다. 실행 입력과 CLI 출력에는 사용자가 입력한 내용이나 도구가 출력한 민감한 정보가 포함될 수 있습니다. iPhone은 연결 주소·PC 식별자·등록 토큰을 기기 키체인에, 기기 식별자·선택 항목·설정·저장된 프롬프트·응답 확인 중인 요청을 앱의 로컬 저장소에 보관합니다. Android도 연결 정보와 설정을 앱의 로컬 저장소에 보관합니다.

PC와 휴대폰 사이의 전송

사용자가 등록한 PC와 휴대폰은 인증된 HTTPS/WebSocket으로 작업, 터미널 입력·출력, 설정 및 실행 상태를 주고받습니다. QR 등록 시 휴대폰이 생성한 식별자와 기기 이름이 선택한 PC에 전달됩니다. QR에는 일회용 등록 정보가 포함되므로 다른 사람에게 공유하지 마세요.

외부 서비스

외부 네트워크 연결에는 Cloudflare Tunnel을 사용합니다. 이 경로로 전송되는 네트워크 정보와 내용은 연결 제공자인 Cloudflare의 서비스 및 개인정보 처리방침에 따라 처리될 수 있습니다. HTTPS는 전송 중 통신을 보호하지만 Cloudflare를 포함한 중계 서비스를 사용하지 않는다는 의미는 아닙니다. Codex 또는 Claude를 실행하면 사용자의 PC에서 해당 CLI와 연결된 제공자에게 작업 내용이 전달될 수 있으며, 해당 제공자의 계정 설정과 개인정보 처리방침이 적용됩니다.

카메라와 클립보드

카메라는 사용자가 QR 스캔을 선택할 때 PC 연결 QR을 읽는 용도로 사용합니다. 카메라 영상은 Tuik 개발자에게 전송하거나 저장하지 않습니다. 클립보드는 사용자가 붙여넣기를 선택할 때 연결 코드 또는 터미널 입력에 사용합니다.

보관과 삭제

PC의 작업·실행 기록은 사용자가 삭제할 때까지 로컬에 남으며 자동 삭제하지 않습니다. PC 앱에서 등록 기기를 해제하면 해당 기기의 접근 권한이 취소됩니다. iPhone의 연결 화면에서 등록 PC를 삭제하면 해당 연결 프로필을 앱에서 제거합니다. iOS 키체인 정보는 OS 정책에 따라 앱 삭제 후에도 남을 수 있으므로 PC에서 기기 권한도 해제하는 것을 권장합니다. 기기 설정 및 로컬 앱 데이터는 앱·운영체제의 저장소 관리 기능으로 삭제할 수 있습니다.
