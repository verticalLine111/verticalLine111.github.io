Tuik 지원 및 사용 방법

Tuik은 사용자가 소유한 Windows·macOS PC의 터미널과 작업 큐를 휴대폰에서 사용하는 원격 클라이언트입니다.

iPhone · iOS 17 이상

Tuik for iPhone

App Store 심사 대기 중 · 버전 1.0

2026년 11월 9일 Apple에 심사를 제출했습니다. 아직 다운로드할 수 없으며, 승인 후 이 페이지에 App Store 다운로드 링크를 안내합니다.

Android 앱처럼 QR로 PC에 연결해 작업 큐 편집·실행, 공통 프롬프트 설정, Codex·Claude 선택과 터미널 입력을 사용할 수 있습니다. 작업은 연결한 PC에서 실행됩니다.

연결 및 사용 방법 ↓ · 개인정보 처리방침

시작하기

  1. 프로젝트 페이지에서 Tuik 데스크톱 설치 파일을 내려받아 PC에 설치합니다.
  2. PC에서 Tuik을 열고 사용할 프로젝트 폴더를 등록합니다.
  3. PC 앱의 ‘휴대폰 연결’을 열어 QR 코드를 표시합니다.
  4. 휴대폰 앱에서 ‘연결 → QR 코드 스캔’을 선택합니다. PC에서 복사한 연결 코드를 붙여넣을 수도 있습니다.
  5. 작업 큐를 편집하거나 셸 터미널을 열어 연결을 확인합니다.

플랫폼별 프롬프트·입력 보호 · 0.9.18

백그라운드 로그가 프롬프트를 덮지 않는지 Windows·macOS·Android·iOS의 실제 Codex 화면 경로로 확인했습니다. 추가로 발견한 Windows의 Shift+Enter 누락과 Android에서 출력과 입력이 겹칠 때 일부 키·붙여넣기가 빠지는 원인도 수정했습니다. 사용자 입력과 터미널 자동응답을 구분하고, 여러 줄 편집·창 크기 변경·모바일 재연결·큐 완료 후 루트 입력을 검사합니다.

macOS·Windows·Android는 0.9.18, Android는 빌드 29입니다. macOS는 Developer ID 서명·공증, Windows는 설치·실행 CI 검증을 거친 미서명 EXE, Android는 개발 키 서명 APK입니다. macOS 호스트에 연결한 Android 16 에뮬레이터와 iOS 26 시뮬레이터에서 네이티브 입력을 확인했습니다. Windows에서는 Android/iOS 형식의 인증된 연결 메시지를 실제 터미널 입력까지 검사했습니다. 실물 휴대폰과 Windows 호스트·네이티브 모바일 화면 조합은 이번에 직접 검증하지 않았습니다. iOS 제품 코드는 변경하지 않았습니다. 0.9.18 릴리스·검증 내역 ↗

Codex 입력 프롬프트 겹침 수정 · 0.9.17

일반 Codex 탭에서 백그라운드 진단 출력이 입력 중인 프롬프트 위에 끼어들던 경로를 수정했습니다. 진단 기록은 별도 파일에 보존하며, 도구 오류가 발생하면 종료 후 기록 위치를 안내합니다. 실제 Codex에서 한글·이모지·여러 줄 입력과 창 크기 변경 중 입력이 유지되는지 확인했습니다.

macOS·Windows 0.9.17을 설치한 뒤 진행 중인 작업을 마치고 Tuik을 완전히 종료·재실행하면 새 실행기에 적용됩니다. Android 앱과 연결 규약은 변경하지 않았으며 기존 0.9.15 APK를 그대로 사용합니다. 0.9.17 릴리스·검증 내역 ↗

큐 완료 후 루트 연결 유지 · 0.9.16

루트 Codex가 작업자처럼 직접 실행한 뒤 큐와 함께 종료되던 원인을 수정했습니다. 이제 루트가 작업별 하위 Codex에 지시하고 검증 결과를 확인하며, 완료된 하위 세션만 종료합니다. 큐가 끝나도 루트 터미널·모바일 입력 연결은 유지됩니다. 새 큐 실행은 새 루트를 열며 기존 루트는 탭을 닫을 때 종료합니다.

PC에서 ‘터미널을 연결 중입니다’ 오류가 나거나 휴대폰에서 터미널 연결이 끊겼다고 표시되던 완료 경로를 수정했습니다. 업데이트 후 진행 중인 작업을 마치고 Tuik을 완전히 종료한 뒤 다시 열어 새 실행기를 적용하세요. Android는 기존 0.9.15 APK를 그대로 사용할 수 있습니다. 0.9.16 릴리스·검증 내역 ↗

Android 터미널 입력 표시 수정 · 0.9.15

데스크톱에서 직접 실행한 Codex를 ‘지금 열린 터미널’로 열어 입력할 때, 조합 중인 글자 뒤에 ‘Ask Codex to do anything’ 안내 문구가 겹쳐 보이던 문제를 수정했습니다. 입력 중에는 안내 문구를 가리고, 조합을 취소하면 다시 표시합니다. 한글 마지막 글자 전송·삭제·붙여넣기 동작을 함께 검증했습니다.

Android 0.9.15 · 빌드 28의 개발 키 서명 APK입니다. Android 16 에뮬레이터에서 검증했으며 실물 휴대폰 검증은 하지 않았습니다. 현재 macOS·Windows 설치 파일은 0.9.18이며 Android 입력 표시 수정도 그대로 유지됩니다. 릴리스와 다운로드 ↗

순차처리 연속 실행·상태 표시 · 0.9.14

Codex의 Worked 표시는 한 턴의 종료이며 큐 전체 완료가 아닙니다. 일반 문장이나 빈 응답으로 턴이 끝나면 같은 세션에서 현재 작업의 완료 상태를 다시 확인합니다. 완료한 작업은 저장하고 다음 대기 작업을 자동으로 전달합니다. 동일한 미완료 보고가 반복되어도 사용자 입력 요청이 없으면 계속합니다. 실제 질문이나 승인 요청은 답변을 기다리며, 완료 상태를 끝내 확인할 수 없는 오류는 표시합니다.

루트 터미널에 실제 순차처리 진행·답변 대기·완료 상태를 표시합니다. 화면 재연결과 실행 중 작업 추가 이후에도 같은 세션에서 세 작업을 순서대로 끝내는 실제 Codex 검증을 통과했습니다.

컨텍스트·사용 한도와 터미널 폭

일반·순차처리 Codex 터미널 하단에 컨텍스트 잔여량과 계정에서 제공하는 5시간·주간 사용 한도를 모델명보다 먼저 표시합니다. 계정에서 제공하지 않는 한도는 표시하지 않습니다. 컨텍스트 상세 수치와 흐린 글자의 대비를 높였으며, 다른 연결에서 터미널 크기가 바뀌어도 앱·탭으로 돌아오거나 터미널을 누르면 현재 창 크기로 복구합니다. 새 실행 설정은 기존 작업을 마치고 앱을 완전히 종료·재실행한 뒤 적용됩니다.

새 PC의 Codex 권한 설정 수정 · 0.9.13

Codex 순차처리·선택 실행의 권한 설정이 PC 기본값에 따라 달라지던 문제를 수정했습니다. 실행 서버와 세션을 승인 생략·전체 접근으로 시작하며, 다음 작업·자동 후속 실행·터미널 재연결에도 같은 설정을 유지합니다. 개인 Codex 설정 파일을 따로 바꿀 필요가 없습니다. 작업 내용에 관한 질문은 계속 답할 수 있습니다. 진행 중인 작업을 마친 뒤 Tuik을 완전히 종료하고 다시 열면 새 실행기에 적용됩니다.

버전 확인과 업데이트

0.9.11에서는 업데이트 실패 원인을 구분해 표시하고, 설치만 실패한 경우 다운로드한 파일을 유지해 설치를 다시 시도합니다. Android 0.9.11은 화면 상단에 설치 버전과 최신 여부를 표시합니다. ‘버전 정보’ 또는 ‘업데이트’에서 공개 APK 버전·빌드 번호를 확인하고 새 APK를 다운로드할 수 있습니다. PC 연결 없이 확인하며, 통신에 실패한 경우 최신 여부를 확인하지 못했다고 표시하고 다시 확인할 수 있습니다.

Mac·Windows 0.9.5부터 앱 상단에서 설치 버전을 확인하고 업데이트 버튼으로 새 버전을 내려받을 수 있습니다. 다운로드 후 ‘업데이트 후 재시작’을 누르면 설치와 재실행이 자동으로 진행됩니다. 0.9.9부터는 실행 중인 터미널·AI 작업과 휴대폰 연결도 유지하며, 같은 세션과 작성 중인 작업·공통 프롬프트 초안으로 돌아옵니다. 설치 중에도 실행은 계속됩니다. 0.9.8 이하에서 처음 업그레이드할 때는 기존 버전에 실행 유지 기능이 없으므로 작업을 마친 뒤 업데이트하세요.

0.9.5 이전 버전에는 업데이트 기능이 없으므로 최신 데스크톱 버전을 한 번 설치해야 합니다. 기존 앱을 삭제할 필요 없이 새 버전을 덮어 설치하면 됩니다. Android에서는 0.9.2부터 연결 화면에서 버전과 빌드 번호를 확인할 수 있습니다.

작업 추가와 확인 필요 작업

Mac·Windows 0.9.9에서는 새 작업을 목록 맨 아래에 추가하면서 보고 있던 위치와 검색·필터를 유지합니다. PC·Android 0.9.9의 확인 필요 탭에서 미완료·실행 오류·중단 작업을 ‘다시 대기’로 바로 옮길 수 있습니다. 내용과 순서는 유지되며, 대기로 옮기는 것만으로 실행하지 않습니다.

Android 작업 큐 상태 보기

Android 0.9.6에서는 작업 큐 상단의 전체·대기·확인 필요·완료 버튼으로 상태별 작업을 골라 볼 수 있습니다. 각 버튼에는 현재 프로젝트의 작업 건수가 표시됩니다. 확인 필요에는 미완료·실행 오류·중단된 작업이 모이며, PC에서 상태를 바꾸면 목록과 건수도 함께 갱신됩니다.

순차처리와 사용자 프롬프트

공통 프롬프트와 현재 작업 원문은 루트와 해당 작업자에게 전달합니다. 0.9.16부터 루트는 지휘자로 유지하고 실제 구현은 작업별 전용 Codex가 수행합니다. 동일 작업의 후속 지시는 같은 작업자가 처리하며, 완료 증거를 확인한 뒤 다음 작업의 새 세션을 시작합니다.

계속 수행할 일이 남은 미완료 턴은 같은 세션에서 자동으로 이어갑니다. 총 호출 횟수 제한은 없습니다. 사용자 결정·질문·승인이 필요한 경우에는 답변을 기다립니다. 0.9.14에서는 같은 미완료 보고의 반복만으로 대기하지 않고 계속 실행합니다. 실제 Codex로 두 작업의 설계 파일 선작성·구현·읽기 검증을 확인했으며, 다른 터미널 제품과의 속도 비교 수치는 주장하지 않습니다.

‘Codex · 루트’ 터미널에서 진행 상황과 추가 지시·질문·승인 응답을 주고받을 수 있습니다. 터미널을 닫으면 실행이 중단됩니다. 작업 큐의 ‘루트 세션 열기/답하기’로 돌아갈 수 있고 모바일 대화도 같은 세션에 연결됩니다. 앱 내 업데이트로 보존된 실행기는 진행 중인 작업이 끝난 뒤 앱을 완전히 종료하고 다시 열어야 새 실행 방식으로 바뀝니다.

대기 화면의 순서 변경·추가 · 0.9.12

순서 변경은 현재 필터와 검색에 보이는 작업을 기준으로 한 칸씩 이동합니다. 숨겨진 완료 작업의 위치는 유지됩니다. 새 작업을 추가하면 현재 필터·검색·스크롤을 보존하면서 추가 성공을 표시합니다. ‘추가한 작업 보기’를 누르면 검색·필터를 풀고 해당 작업으로 이동합니다.

모델과 추론 강도

Codex 실행 창에서 모델을 고르면 그 모델이 지원하는 low·medium·high 등의 추론 강도와 기본값이 표시됩니다. 선택한 모델·강도는 함께 표시되고, PC·프로젝트·모델별로 저장됩니다. 큐 실행과 후속 답변에도 같은 설정을 적용합니다. Android 0.9.2에서도 같은 선택을 지원하며, PC의 Tuik 0.9.5 이상이 필요합니다.

사용 조건

연결한 PC와 Tuik 데스크톱 앱이 켜져 있어야 합니다. 일반 셸 터미널에는 AI 계정이 필요하지 않습니다. Codex·Claude 작업 실행은 해당 PC에 사용자가 설치하고 로그인한 CLI를 사용합니다. iPhone에서는 AI 모델이나 PC 명령을 직접 실행하지 않습니다.

QR 스캔 개선 · 0.9.8

PC에서 QR을 더 크고 선명하게 표시하며 작은 창에서도 QR 전체가 보입니다. Android 0.9.8에는 연속 자동초점과 넓은 인식 영역, 조명 버튼을 적용했습니다. QR의 흰 여백까지 네모 안에 비추고, 너무 가까우면 조금 떨어뜨려 초점이 맞도록 해 주세요. 화면 반사가 있으면 조명을 끄세요. PC·Android 앱을 함께 업데이트해 주세요.

연결이 안 될 때

PC의 Tuik과 인터넷 연결을 확인하고 휴대폰에서 재연결을 누르세요. PC 앱이나 터널을 다시 시작했거나 QR이 만료됐다면 PC에서 새 QR을 표시한 뒤 다시 등록하세요. PC에서 등록 기기를 해제하면 해당 기기의 연결 권한이 취소됩니다.

작업과 터미널

작업 추가·수정·삭제·순서 변경, 공통 프롬프트 저장 및 ON/OFF, 전체·선택 실행, 중단과 미완료 작업 이어서 실행을 지원합니다. 터미널은 실제 PC의 셸 또는 설치된 AI CLI에 연결됩니다. 휴대폰이 백그라운드로 이동하면 연결을 닫고 다시 열 때 상태와 출력을 이어받습니다.
