Tuik 지원 및 사용 방법

Tuik은 사용자가 소유한 Windows·macOS PC에서 작업을 실행하는 데스크톱 앱과, 그 터미널·작업 큐에 연결하는 iPhone·Android·Mac 클라이언트로 구성됩니다.

Connect an iPhone or iPad to your computer

With Tuik open on your iPhone or iPad, use a Mac or Windows PC to try a shared task queue and terminal. Both devices need internet access. These steps work without an AI account.

  1. Set up the computer. Download the free Tuik desktop host. Choose the macOS DMG or Windows installer. Install and open Tuik, then create an empty folder called Tuik Review. Click the plus beside 프로젝트 (Projects) and select that folder. Keep Tuik running and the computer awake.
  2. Pair the devices. On the computer, click 휴대폰 연결 (Phone Connection). On the iPhone or iPad, tap PC 연결 (Connect to PC), then QR 코드 스캔 (Scan QR Code) and scan the code. In iOS build 12 or later, open 연결 PC (PCs) and tap PC 추가 (Add PC) for each additional computer. Tap a saved computer to switch. In build 13 or later, use the edit button beside a computer to set a name on this device. To pair manually, click 연결 코드 복사 (Copy Connection Code) on the computer. Paste the code into the connection field on the iOS device and tap 연결 코드로 등록 (Register). Each code works once and expires after 10 minutes. Click 새 QR (New QR) if you need a fresh code.
  3. Check the shared queue. Select Tuik Review on both devices. On the iOS device, open 작업 큐 (Task Queue), type Check the connection and tap 작업 추가 (Add Task). Open the same project’s task queue on the computer. You should see the task you just added.
  4. Check the shared terminal. On the iOS device, open 터미널 (Terminal), tap the ellipsis menu 터미널 관리 (Manage Terminals), then choose 새 셸 (New Shell). On the computer, open Terminal and select that same shell tab. On the iOS device, type echo Tuik-review and tap Enter. The shell runs on the computer, and both screens display Tuik-review on its own line.

Mac 클라이언트 · 버전 1.1

Tuik Connect for Mac

Mac App Store 심사 대기 중. 버전 1.1(빌드 2)을 2026년 11월 18일 오후 4시 58분(KST)에 심사 제출했습니다. Mac에 별도로 적용했던 주황색 UI 강조색을 제거하고 기존 UI 색상으로 복원했습니다. 실제 HTTPS 연결 등록, 셸 입력, 재연결과 앱 종료·재실행 뒤 추가 입력을 검증했습니다. Apple 승인 후 자동 출시하도록 설정했으며, 아직 승인이나 공개 출시가 완료된 상태는 아닙니다. 일반 다운로드 링크는 승인 후 안내합니다.

Tuik Connect는 별도로 실행 중인 Tuik 데스크톱 호스트에 연결하는 앱입니다. 같은 Mac에서 사용하려면 이 사이트의 무료 macOS 호스트를 함께 설치하고 실행해야 합니다. 다른 Mac 또는 Windows PC의 호스트에도 연결할 수 있습니다. 작업·셸·AI CLI는 호스트에서 실행되며, Tuik Connect에 호스트가 포함되거나 자동 설치되지는 않습니다.

  1. 프로젝트 페이지에서 macOS 또는 Windows용 Tuik 호스트를 설치하고 프로젝트 폴더를 등록합니다.
  2. 호스트의 ‘휴대폰 연결’에서 연결 코드를 복사합니다.
  3. Tuik Connect의 ‘PC 연결’에 붙여넣고 ‘연결 코드로 등록’을 선택합니다. Mac에서는 카메라가 필요하지 않습니다. 코드는 한 번만 사용할 수 있고 10분 뒤 만료됩니다.

호스트와 클라이언트 모두 인터넷 연결이 필요합니다. 같은 Mac에서도 현재 연결은 HTTPS 터널을 사용합니다. 연결 코드는 다른 사람에게 공유하지 마세요. 연결에 실패하면 호스트의 인터넷 상태를 확인하고 새 코드를 발급해 등록하세요.

Tuik Connect.app과 Tuik.app은 함께 설치할 수 있는 별도 앱입니다. Tuik Connect를 닫아도 호스트의 작업은 계속되며, 작업을 멈추려면 ‘실행 중단’을 선택합니다. App Store판 Tuik Connect의 업데이트는 Mac App Store에서 제공하고, 별도 Tuik 호스트는 아래 데스크톱 업데이트 방법을 따릅니다.

순차처리 작업자 유지와 새 아이콘 · 0.9.28

작업자를 실행한 뒤 루트의 턴이 먼저 끝나도 작업자 결과를 확인할 때까지 현재 작업을 유지합니다. 이전 루트 턴의 종료 알림으로 실행 중인 작업자를 취소하던 경로도 수정했습니다. 실제 실패·중단은 별도로 기록하고 다음 작업은 실행하지 않으며, 정상 완료 뒤에는 같은 루트 터미널에서 계속 입력할 수 있습니다.

macOS·Windows·Android의 앱 아이콘을 밝은 바탕의 T 모노그램과 주황색 커서로 바꿨습니다. Android는 런처 모양에 맞는 적응형 아이콘을 사용합니다. 사이트의 Android 0.9.28 다운로드는 빌드 35 개발 키 서명 APK입니다. 별도 Google Play 빌드 35도 기존 내부 테스트 트랙에 제공했습니다. 일반 공개 스토어 출시는 아닙니다. iOS의 같은 아이콘은 Apple 처리가 끝난 빌드 1.1(10)에 포함됐으며 내부 TestFlight 제공과 공개 승인은 구분합니다.

시작하기

  1. 프로젝트 페이지에서 Tuik 데스크톱 설치 파일을 내려받아 PC에 설치합니다.
  2. PC에서 Tuik을 열고 사용할 프로젝트 폴더를 등록합니다.
  3. PC 앱의 ‘휴대폰 연결’을 열어 QR 코드를 표시합니다.
  4. 휴대폰에서 PC를 처음 연결할 때 QR을 스캔합니다. 다음 PC는 ‘연결 PC → PC 추가’에서 등록합니다. PC에서 복사한 연결 코드를 붙여넣을 수도 있습니다.
  5. 작업 큐를 편집하거나 셸 터미널을 열어 연결을 확인합니다.

완료한 작업을 최신순으로 · 0.9.27

작업 큐 ‘완료’ 탭에서 가장 최근에 완료한 작업이 맨 위에 표시됩니다. 완료 시각을 저장하므로 내용을 편집하거나 앱을 다시 연결해도 정렬이 유지됩니다. 대기로 돌린 작업을 다시 완료하면 새 완료 시각으로 맨 위에 표시합니다. 대기·전체 탭의 실행 순서는 유지합니다.

이전 버전에서 완료한 작업에는 완료 시각이 저장되어 있지 않았습니다. 이 항목은 시각이 있는 작업 아래에 작업 번호 최신순으로 표시합니다. 새 완료부터는 실제 완료 순서를 저장합니다.

Codex 후속 대화 입력 복구 · 0.9.26

질문·승인을 기다리던 Codex 응답이 실패하거나 중단된 뒤에도 대기 요청이 남아 다음 대화를 막던 경로를 수정했습니다. 끝난 응답에 속한 요청을 정리해 PC와 모바일의 입력창이 같은 상태를 보도록 했습니다. 작업 큐 완료, 응답 실패·중단, 터미널 종료는 별도 상태로 처리하며 루트 대화와 터미널은 계속 유지합니다.

PC·모바일 터미널 폭과 스크롤 수정 · 0.9.25

PC와 모바일이 같은 터미널을 동시에 볼 때 모바일의 작은 창이 PC의 줄 폭을 바꾸고, PC를 다시 선택하면 모바일 글자와 커서가 어긋나던 문제를 수정했습니다. PC 화면이 연결되어 있는 동안 PC 크기를 유지하며, Android는 같은 터미널 화면을 읽기 쉬운 글자 크기로 표시합니다. iOS 화면 배치는 내부 테스트에서 추가 개선 중입니다. 넓은 줄은 가로로 이동하고, 두 손가락으로 화면을 이동하거나 확대·축소할 수 있습니다. Codex 기록은 세로 스크롤로 탐색합니다.

PC 화면을 닫으면 연결된 모바일의 크기를 적용하고, PC가 돌아오면 다시 PC 크기를 사용합니다. 이 과정에서 실행 중인 대화와 터미널은 유지합니다. 업데이트 직후 기존 실행 서버가 남아 있는 동안에는 모바일이 기존 화면 크기를 읽어 맞춥니다. 새 실행 서버의 모든 수정 사항은 진행 중인 작업을 마치고 Tuik을 완전히 종료한 뒤 다시 실행하면 적용됩니다.

일반·순차처리 Codex 터미널 하단에 컨텍스트 잔여량과 계정에서 제공하는 5시간·주간 사용 한도를 모델명보다 먼저 표시합니다. 계정에서 제공하지 않는 한도는 표시하지 않습니다. 컨텍스트 상세 수치와 흐린 글자의 대비를 높였으며, 다른 연결에서 터미널 크기가 바뀌어도 앱·탭으로 돌아오거나 터미널을 누르면 현재 창 크기로 복구합니다. 새 실행 설정은 기존 작업을 마치고 앱을 완전히 종료·재실행한 뒤 적용됩니다.

새 PC의 Codex 권한 설정 수정 · 0.9.13

Codex 순차처리·선택 실행의 권한 설정이 PC 기본값에 따라 달라지던 문제를 수정했습니다. 실행 서버와 세션을 승인 생략·전체 접근으로 시작하며, 다음 작업·자동 후속 실행·터미널 재연결에도 같은 설정을 유지합니다. 개인 Codex 설정 파일을 따로 바꿀 필요가 없습니다. 작업 내용에 관한 질문은 계속 답할 수 있습니다. 진행 중인 작업을 마친 뒤 Tuik을 완전히 종료하고 다시 열면 새 실행기에 적용됩니다.

0.9.13 릴리스·검증 내역 ↗

버전 확인과 업데이트

아래 macOS·Windows 업데이트 안내는 이 사이트에서 내려받는 Tuik 데스크톱 호스트에 해당합니다. App Store판 Tuik Connect 클라이언트는 Mac App Store에서 업데이트합니다.

0.9.11에서는 업데이트 실패 원인을 구분해 표시하고, 설치만 실패한 경우 다운로드한 파일을 유지해 설치를 다시 시도합니다. Android 0.9.11은 화면 상단에 설치 버전과 최신 여부를 표시합니다. ‘버전 정보’ 또는 ‘업데이트’에서 공개 APK 버전·빌드 번호를 확인하고 새 APK를 다운로드할 수 있습니다. PC 연결 없이 확인하며, 통신에 실패한 경우 최신 여부를 확인하지 못했다고 표시하고 다시 확인할 수 있습니다.

Mac·Windows 0.9.5부터 앱 상단에서 설치 버전을 확인하고 업데이트 버튼으로 새 버전을 내려받을 수 있습니다. 다운로드 후 ‘업데이트 후 재시작’을 누르면 설치와 재실행이 자동으로 진행됩니다. 0.9.9부터는 실행 중인 터미널·AI 작업과 휴대폰 연결도 유지하며, 같은 세션과 작성 중인 작업·공통 프롬프트 초안으로 돌아옵니다. 설치 중에도 실행은 계속됩니다. 0.9.8 이하에서 처음 업그레이드할 때는 기존 버전에 실행 유지 기능이 없으므로 작업을 마친 뒤 업데이트하세요.

0.9.5 이전 버전에는 업데이트 기능이 없으므로 최신 데스크톱 버전을 한 번 설치해야 합니다. 기존 앱을 삭제할 필요 없이 새 버전을 덮어 설치하면 됩니다. Android에서는 0.9.2부터 연결 화면에서 버전과 빌드 번호를 확인할 수 있습니다.

작업 추가와 확인 필요 작업

Mac·Windows 0.9.9에서는 새 작업을 목록 맨 아래에 추가하면서 보고 있던 위치와 검색·필터를 유지합니다. PC·Android 0.9.9의 확인 필요 탭에서 미완료·실행 오류·중단 작업을 ‘다시 대기’로 바로 옮길 수 있습니다. 내용과 순서는 유지되며, 대기로 옮기는 것만으로 실행하지 않습니다.

Android 작업 큐 상태 보기

Android 0.9.6에서는 작업 큐 상단의 전체·대기·확인 필요·완료 버튼으로 상태별 작업을 골라 볼 수 있습니다. 각 버튼에는 현재 프로젝트의 작업 건수가 표시됩니다. 확인 필요에는 미완료·실행 오류·중단된 작업이 모이며, PC에서 상태를 바꾸면 목록과 건수도 함께 갱신됩니다.

순차처리와 사용자 프롬프트

공통 프롬프트와 현재 작업 원문은 루트와 해당 작업자에게 전달합니다. 0.9.16부터 루트는 지휘자로 유지하고 실제 구현은 작업별 전용 Codex가 수행합니다. 동일 작업의 후속 지시는 같은 작업자가 처리하며, 완료 증거를 확인한 뒤 다음 작업의 새 세션을 시작합니다.

계속 수행할 일이 남은 미완료 턴은 같은 세션에서 자동으로 이어갑니다. 총 호출 횟수 제한은 없습니다. 사용자 결정·질문·승인이 필요한 경우에는 답변을 기다립니다. 0.9.14에서는 같은 미완료 보고의 반복만으로 대기하지 않고 계속 실행합니다. 실제 Codex로 두 작업의 설계 파일 선작성·구현·읽기 검증을 확인했으며, 다른 터미널 제품과의 속도 비교 수치는 주장하지 않습니다.

‘Codex · 루트’ 터미널에서 진행 상황과 추가 지시·질문·승인 응답을 주고받을 수 있습니다. 터미널을 닫으면 실행이 중단됩니다. 작업 큐의 ‘루트 세션 열기/답하기’로 돌아갈 수 있고 모바일 대화도 같은 세션에 연결됩니다. 앱 내 업데이트로 보존된 실행기는 진행 중인 작업이 끝난 뒤 앱을 완전히 종료하고 다시 열어야 새 실행 방식으로 바뀝니다.

대기 화면의 순서 변경·추가 · 0.9.12

순서 변경은 현재 필터와 검색에 보이는 작업을 기준으로 한 칸씩 이동합니다. 숨겨진 완료 작업의 위치는 유지됩니다. 새 작업을 추가하면 현재 필터·검색·스크롤을 보존하면서 추가 성공을 표시합니다. ‘추가한 작업 보기’를 누르면 검색·필터를 풀고 해당 작업으로 이동합니다.

모델과 추론 강도

Codex 실행 창에서 모델을 고르면 그 모델이 지원하는 low·medium·high 등의 추론 강도와 기본값이 표시됩니다. 선택한 모델·강도는 함께 표시되고, PC·프로젝트·모델별로 저장됩니다. 큐 실행과 후속 답변에도 같은 설정을 적용합니다. Android 0.9.2에서도 같은 선택을 지원하며, PC의 Tuik 0.9.5 이상이 필요합니다.

사용 조건

연결한 PC와 Tuik 데스크톱 앱이 켜져 있어야 합니다. 일반 셸 터미널에는 AI 계정이 필요하지 않습니다. Codex·Claude 작업 실행은 해당 PC에 사용자가 설치하고 로그인한 CLI를 사용합니다. iPhone에서는 AI 모델이나 PC 명령을 직접 실행하지 않습니다.

QR 스캔 개선 · 0.9.8

PC에서 QR을 더 크고 선명하게 표시하며 작은 창에서도 QR 전체가 보입니다. Android 0.9.8에는 연속 자동초점과 넓은 인식 영역, 조명 버튼을 적용했습니다. QR의 흰 여백까지 네모 안에 비추고, 너무 가까우면 조금 떨어뜨려 초점이 맞도록 해 주세요. 화면 반사가 있으면 조명을 끄세요. PC·Android 앱을 함께 업데이트해 주세요.

연결이 안 될 때

PC의 Tuik과 인터넷 연결을 확인하고 휴대폰에서 재연결을 누르세요. PC 앱이나 터널을 다시 시작했거나 QR이 만료됐다면 PC에서 새 QR을 표시한 뒤 다시 등록하세요. PC에서 등록 기기를 해제하면 해당 기기의 연결 권한이 취소됩니다.

작업과 터미널

작업 추가·수정·삭제·순서 변경, 공통 프롬프트 저장 및 ON/OFF, 전체·선택 실행, 중단과 미완료 작업 이어서 실행을 지원합니다. 터미널은 실제 PC의 셸 또는 설치된 AI CLI에 연결됩니다. 휴대폰이 백그라운드로 이동하면 연결을 닫고 다시 열 때 상태와 출력을 이어받습니다.
